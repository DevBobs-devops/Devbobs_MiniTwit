\section{Use of Generative AI}\label{use-of-generative-ai}
Generative AI have primarilly been used for debugging errors and understanding new tools.
It was also used for code assistance, especially with new syntax that was unfamilar to us.
We have primarilly used ChatGPT and Claude AI.
They have been co-authored when they have been used, often with a small message, explaining what they helped with.
AI have also been used to catch potential errors by e.g. confirming syntax before running a new GitHub workflow.
Obviously, there is a possibility of loss of learning, as
AI speeds up the problemsolving process, sometimes highlighting issues
we had not observed yet.
When writing this report, we discovered that we wrote Co-authors of the AI's was in a wrong format missing an email.
We could therefore not include them in the mailmap. 
Instead they can be found by going though the gitlog and grep'ing Claude and ChatGPT.
The total number of commits co-authored with AI: 30.
